# Shelfcount

**[Download Shelfcount](https://evansmith1377.github.io/shelfcount/download.html)** — Windows or Linux.
One folder, no installer, no admin rights.

Shelfcount is an offline-first barcode inventory app for school textbooks. It
runs on one laptop, stores everything in a single file next to itself, and
needs no server and no account.

This repository is not the source. It holds two things, both published
automatically:

- **The website** at <https://evansmith1377.github.io/shelfcount/> — every file here is generated from
  `site/` in the source repository and force-pushed on each change, so an
  edit made here is overwritten by the next deploy.
- **The releases** — the per-platform archives and their `SHA256SUMS`
  manifest, attached to each tag. The download buttons on the site and
  Shelfcount's own updater both fetch from here.
